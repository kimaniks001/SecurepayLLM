## Matrix reading rules

- Severity is attached to the human visibility problem, not the backend capability itself.
- A capability can be correctly contextual and therefore have no need for permanent screen space.
- 'Scales?' refers to the interaction pattern, not backend data integrity.
- Phase assignments are exclusive: every correction belongs to exactly one later Human Convergence phase.
- Skills Institute and Financial Institutions rows are failures because backend capability exists but the current first-party human product does not provide a corresponding usable experience.
- Community/Circles rows are largely preservation rows; Phase 9 should certify them rather than redesign them unless later evidence finds a regression.
